# Raw Idea: Mobile UI/UX improvements and multiplayer experience enhancements

## User Description

1. Add "Continue" button in MP round results - both players can skip 10s wait, counter shows on button, instant advance when all players click
2. Change final round message from "Next round in X..." to "Calculating results..."
3. Show cumulative total score alongside round score in each round summary
4. Add time-based bonus scoring - faster pin placement = more points, need calculation formula
5. Fix text overlap on smartphones (iPhone 14 Pro) - ensure no scrolling needed, all content visible
6. Add "Back to Main Menu" button in multiplayer menu/lobby
7. Standardize font colors across all cards for consistency
8. Use main menu gradient background on MP final summary screen instead of plain black
9. Add confetti animation for winner on MP final summary (auto-play 1 second after results show) using Preline confetti: https://preline.co/docs/confetti.html

This spec focuses on polishing the multiplayer experience and fixing mobile UI issues.
